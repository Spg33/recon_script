recondir.sh sets up a tidy, repeatable directory structure for a penetration testing engagement. Pass it a target IP or domain and it creates a parent folder named after the target with nmap/, exploits/, web/, and notes/ subdirectories, then drops a structured notes.md template (Scope, Initial Recon, Vulnerability Analysis, Exploitation, Post-Exploitation) so you can start documenting findings immediately. Includes argument validation, safe-by-default error handling, and clean, commented code.
